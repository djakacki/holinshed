# GUI Launcher

Start the GUI with the launcher for your OS:

- Windows: double-click `run_extract_names_gui.bat`
- macOS: double-click `run_extract_names_gui.command`
- Linux: run or double-click `run_extract_names_gui.sh`

In the window:

1. Choose the authority CSV.
2. Choose the XML file.
3. Click `Run Extraction`.

The GUI remembers the last files you used.
